# I-5 – Translasi Alamat dan Manajemen Memori

Repositori ini berisi dokumentasi pengerjaan Tugas I-5 mata kuliah **Sistem Operasi**, dengan materi Translasi Alamat dan Manajemen Memori.

## Pembahasan

Tugas ini membahas beberapa konsep dalam manajemen memori, yaitu:

1. Translasi alamat logis ke alamat fisik.
2. Perbandingan ukuran page 4 KB dan 2 MB.
3. Translation Lookaside Buffer (TLB) dan TLB reach.
4. Effective Access Time (EAT).
5. Perhitungan ukuran page table.
6. Fragmentasi internal.

## Implementasi

Perhitungan dan analisis diverifikasi menggunakan Python. Program dapat dijalankan dengan perintah:

```bash
python translasi_alamat.py
```

## Dokumentasi

Hasil pengamatan lingkungan virtual machine dan keluaran program disertakan pada folder `dokumentasi/`.
